# Run wait/progress Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add opt-in `winbridge run --wait` progress and a render return code without changing default launcher behavior.

**Architecture:** `run_app` gains lifecycle callbacks; `verify` exposes its observe-only loop as `watch_launch`; the CLI composes kill/background/launch/watch under one app lock and prints staged human or NDJSON progress.

**Tech Stack:** Python 3.11, Typer, pytest, Pillow, existing Wine/Desktop fakes.

**Spec:** `docs/superpowers/specs/2026-10-28-run-wait-progress-design.md`

## Global Constraints

- Run project commands only through `scripts/sandbox` from a worktree; never host-native `uv`, Wine, or desktop commands.
- No `shell=True`, no root, no `sudo`; app-agnostic and NDA-safe (no vendor names or artifacts).
- Do not change default `run`/`--restart` blocking or exit semantics.
- `--wait` exits 0 only after two visible frames from a launch it owns; otherwise 4 (`transparent`, `background`, `timeout`, `already-running`) or 3 (unsupported desktop).
- Use `--wait` plus `--timeout SECS`; `--wait` alone defaults to 300. Typer cannot express `--wait[=secs]`.
- Local-only; no push, remote, or publish.

## Review Focus

- Already-running + `--wait` must not claim an unobserved instance is painted; it exits 4 with `already-running`.
- Background capture failure must happen after any requested kill but before spawn, and must exit 4 without launching.
- Unsupported desktop must be rejected before the kill, so a failed wait cannot destroy a running instance.
- Human and NDJSON output must be mutually exclusive on stdout; JSON lines must parse independently.
- The per-app lock must cover background capture, launch, and observation so a concurrent `run`/`verify` cannot change the target mid-wait.

def test_restart_reports_stages_and_prestart_hook_order(
    monkeypatch: pytest.MonkeyPatch,
    fake_backend: Any,
    profile: Profile,
    paths: Paths,
) -> None:
    order: list[str] = []
    events: list[tuple[str, str]] = []
    monkeypatch.setattr(
        "winbridge.core.run.kill_prefix",
        lambda backend, prefix: order.append("kill"),
    )
    monkeypatch.setattr(
        fake_backend,
        "run",
        lambda prefix, exe, argv: order.append("run") or fake_backend.popen,
    )

    run_app(
        profile,
        paths,
        fake_backend,
        restart=True,
        proc_probe=lambda _: {1},
        before_start=lambda: order.append("before_start"),
        on_stage=lambda stage, status: events.append((stage, status)),
    )

    assert order == ["kill", "before_start", "run"]
    assert events == [
        ("stop", "stopping"),
        ("stop", "stopped"),
        ("launch", "starting"),
        ("launch", "started"),
    ]

def test_watch_launch_observes_without_killing_or_launching(
    tmp_path: Path,
    profile: Profile,
    paths: Paths,
    fake_backend: Any,
    fake_desktop: Any,
) -> None:

    background = capture_background(fake_desktop, run_dir)
    events: list[tuple[str, str]] = []

        launch,
        paths.prefix_for(profile.id),

        capture_s=0.001,

    assert result.reason == "passed"
    assert result.evidence_dir == run_dir
    assert fake_backend.runs == []
    assert events == [

        ("paint", "visible"),

- Produces:
