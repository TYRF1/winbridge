# Glossary

- **Wine** — the compatibility layer that runs Windows binaries on Linux.
- **Prefix** — Wine's per-app fake `C:` drive (`WINEPREFIX`), including its
  registry and user profile. WinBridge keeps one per app.
- **Bottle** — Bottles' managed prefix. WinBridge does not require Bottles; the
  v0.2 backend can use one.
- **Runner** — a specific Wine build used to execute the prefix (for example
  `soda@11.0-10`). The runner decides whether an app renders and whether the
  cursor works; WinBridge pins one per app.
- **WebView2 Evergreen** — Microsoft's Edge WebView2 runtime, required by Tauri
  2.x on Windows. It is not bundled by Tauri installers and must be installed
  before the app.
- **Tauri** — the app framework whose Windows builds use WebView2. WinBridge's
  supported app class.
- **Scheme / URL protocol** — a custom URL scheme registered by the app (for
  example `example-app://callback`). Used for login callbacks.
- **Pin** — a launcher entry in the desktop's bar/taskbar. On Omarchy this is the
  omarchy-shell taskbar plugin, configured in `~/.config/omarchy/shell.json`.
- **Bridge** — WinBridge's host-side forwarding of a callback URL into the
  running Wine app. Experimental in v0.1.
- **Verify** — the smoke harness: launch, wait for first paint, screenshot,
  decide PASS/FAIL, keep evidence.
- **Evidence** — screenshots and logs stored per app/version under
  `~/.local/share/winbridge/evidence/`.
- **XWayland** — the X11 compatibility path under Wayland; Wine apps run there.
- **DXVK** — the Direct3D-to-Vulkan layer used by Wine; its shader cache makes
  first paint slow.
- **Profile** — WinBridge's versioned TOML record of an app: exe, schemes,
  runner, installer, exposed folders, pin match. Generated by setup, editable.
